## 2. 영역별 상세 컴포넌트 명세

### 2.1 상단 액션 바 (Top Action Bar)
- **높이:** `52px` (모바일 상단 고정, backdrop-blur 적용)
- **좌측 상태 표시:** 녹색 펄스 뱃지 (`🟢 활동 중` / `✨ 프로젝트 구상 중`)
- **우측 액션 버튼:**
  - **QR 코드 버튼:** 클릭 시 모바일 카메라 스캔용 QR 팝업 모달 노출
  - **공유 버튼:** 모바일 접속 시 Web Share API 네이티브 공유 창 호출, 데스크톱 접속 시 URL 클립보드 복사

---

### 2.2 프로필 헤더 (Profile Header)
- **아바타:** `80px x 80px` 원형 이미지 (그라데이션 링 테두리 및 그림자)
- **이름 (Name):** `20px` Bold 텍스트
- **고유 닉네임 (Slug):** `12px` 텍스트 (`@username`)
- **소개글 (Bio):** 최대 2~3줄 분량 (줄간격 1.5, 모바일 가독성 최적화)
- **소셜 아이콘 퀵바:** 32px 원형 아이콘 버튼 (GitHub, Instagram, Velog, Email 등)

---

### 2.3 미디어 임베드 영역 (Media Block)
- **유튜브 비디오:** `16:9` 반응형 비율 컨테이너, 페이지 이탈 없이 인라인 재생
- **음악 플레이어 (스포티파이/사운드클라우드):** 높이 80px 콤팩트 임베드 위젯

---

### 2.4 링크 블록 리스트 (Links List)
- **카드 규격:** 높이 `56px~64px` 이상의 터치 친화적 패딩
- **컴포넌트 구성:**
  - `Icon`: 40px 라운드 아이콘 컨테이너
  - `Title`: 15px 볼드 타이틀 (말줄임표 `text-overflow: ellipsis` 처리)
  - `Description`: 12px 서브 텍스트
  - `Badge`: `대표`, `NEW`, `HOT` 등의 강조 태그 (선택 사항)
  - `Action`: 우측 쉐브론(`>`) 화살표 및 복사 버튼

---

### 2.5 인터랙티브 응원 블록 (Cheer Section)
- 방문자가 회원가입 없이 가볍게 클릭으로 응원을 남길 수 있는 하트 버튼
- 클릭 시 플로팅 하트 이펙트 및 누적 카운터 증가

---

### 2.6 바이럴 푸터 배너 (Viral Footer)
- *"✨ 마이링크로 나만의 페이지 만들기"* 풀필(Pill) 버튼 제공
- 신규 방문자가 마이링크 플랫폼 회원으로 유입될 수 있도록 유도
- 카피라이트 및 플랫폼 브랜딩 문구 표시
